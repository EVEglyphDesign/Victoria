# Reference Assessment — evaluation wireframes (public reflection)

Public reflection (fork) of the seven-dimension reference-assessment wireframe
whose canon source of truth lives in the private
[`eve-glyph-education`](https://github.com/EVEglyphDesign/eve-glyph-education)
repo at `assessment-service/wireframes/`. Reflected here into public Victoria so
it can be served live on GitHub Pages.

## Live URL

Published at **`/assessment/`** on the Victoria Pages site:
<https://eveglyphdesign.github.io/Victoria/assessment/>

Linked from the root map; a "← Map" link returns from this page to the map.

## What it is

Low-fidelity wireframes for the six evaluation surfaces named as not-yet-built
in the assessment service (structured intake, routing rules engine, footprint
trace format, live-stream surface, public-domain event correlation, public
archive), plus the seven-dimension reading that binds them to the Starship
Academy scores.

**Wireframe only** — structure and flow, not final visual design. No live data,
no backend. A single self-contained static HTML file (fonts via Fontshare CDN);
nothing else to build. The canon repo is the source of truth; changes flow
EDU → here.
