# How to contribute (to your own twin)

This repo is yours. "Contributing" just means adding bearings — small, honest files that sharpen the model of you.

## The loop

1. **Pick a layer** — `identity/`, `capability/`, or `values/`.
2. **Read its README** for prompts.
3. **Add a file** answering whatever's easy. A few sentences beats a blank page.
4. **Commit** with a plain message: `add: how I approach hard problems`.
5. **Repeat.** Every file is one more line crossing the same point.

## Style

- Write in your own voice, first person. The twin should sound like you, not like a form.
- Short and true > long and polished.
- One idea per file is fine. Small commits are good.

## What not to add

- Anything about other people without their say-so.
- Raw data dumps — summarize instead (see `data-export/`).
- Anything you'd want deleted later. If in doubt, leave it out; you can always add it.

## Done is a moving target

There's no "finished." The twin is good enough when its answers start sounding like yours — and it keeps getting better every time you add a file.
